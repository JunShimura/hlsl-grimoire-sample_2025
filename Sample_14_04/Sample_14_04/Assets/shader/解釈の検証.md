# 解釈の検証：DirectXMath と HLSL の相互運用

## ユーザーの解釈

> DirectXはv × M形式で演算する、行優先(row-major)でメモリに格納、HLSL側が列優先として解釈すると、行優先メモリを列優先として読み取るため、実質的に転置されたように解釈され、M × v形式で演算されるから上手くいく

## 検証

### 1. DirectXMathの行ベクトル形式（v × M）

```
[x', y', z', w'] = [x, y, z, w] × [m00  m01  m02  m03]
									[m10  m11  m12  m13]
									[m20  m21  m22  m23]
									[m30  m31  m32  m33]

計算式：
x' = x*m00 + y*m10 + z*m20 + w*m30
y' = x*m01 + y*m11 + z*m21 + w*m31
z' = x*m02 + y*m12 + z*m22 + w*m32
w' = x*m03 + y*m13 + z*m23 + w*m33
```

### 2. C++側のメモリ配置（行優先）

```
メモリ: [m00, m01, m02, m03, m10, m11, m12, m13, m20, m21, m22, m23, m30, m31, m32, m33]
		 ↑行0              ↑行1              ↑行2              ↑行3
```

### 3. GPU転送（memcpy、転置なし）

```
GPU上のメモリ: [m00, m01, m02, m03, m10, m11, m12, m13, m20, m21, m22, m23, m30, m31, m32, m33]
				↑そのまま転送
```

### 4. HLSLの列優先解釈

HLSLが列優先として解釈すると、メモリの読み取り方が変わります：

```
HLSL側の論理的な行列表現（列優先解釈）:
	   [列0  列1  列2  列3]
[行0]  m00   m10   m20   m30
[行1]  m01   m11   m21   m31
[行2]  m02   m12   m22   m32
[行3]  m03   m13   m23   m33
```

これは、元の行列を**転置した形**です！

### 5. HLSL での mul(M, v) の計算

```
[x']   [m00  m10  m20  m30]   [x]
[y'] = [m01  m11  m21  m31] × [y]
[z']   [m02  m12  m22  m32]   [z]
[w']   [m03  m13  m23  m33]   [w]

計算式：
x' = m00*x + m10*y + m20*z + m30*w
y' = m01*x + m11*y + m21*z + m31*w
z' = m02*x + m12*y + m22*z + m32*w
w' = m03*x + m13*y + m23*z + m33*w
```

### 6. 結果の比較

**DirectXMath（v × M）の結果**:
```
x' = x*m00 + y*m10 + z*m20 + w*m30
y' = x*m01 + y*m11 + z*m21 + w*m31
z' = x*m02 + y*m12 + z*m22 + w*m32
w' = x*m03 + y*m13 + z*m23 + w*m33
```

**HLSL（M × v）の結果**:
```
x' = m00*x + m10*y + m20*z + m30*w
y' = m01*x + m11*y + m21*z + m31*w
z' = m02*x + m12*y + m22*z + m32*w
w' = m03*x + m13*y + m23*z + m33*w
```

**完全に一致！** ✅

## 結論：解釈は正しい

ユーザーの解釈は**完全に正しい**です。

### 仕組みのまとめ

```
C++側（v × M）
	↓
行優先メモリに格納
	↓
GPU転送（転置なし）
	↓
HLSL側で列優先として解釈
	↓
実質的に転置（M^T）
	↓
mul(M, v) = mul(M^T, v) = v × M（元の形式）
	↓
結果が一致！
```

### 数学的な説明

行列の転置の性質：
```
(v × M)^T = M^T × v^T

v を列ベクトルとして扱うと：
v × M = M^T × v
```

つまり：
- C++: 行ベクトル × 行列（v × M）
- HLSL: 転置された行列 × 列ベクトル（M^T × v）
- 結果: 数学的に等価！

✅ 行優先メモリを列優先として読み取る
✅ **実質的に転置** されたように解釈される
✅ **M × v** 形式で演算される
